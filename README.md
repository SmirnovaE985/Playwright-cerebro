# Cerebro E2E — автоматизированное тестирование проекта Контакт-центр

Цель проекта — обеспечить автоматизированную проверку ключевых пользовательских сценариев системы **Cerebro** с помощью **Playwright**.

Cerebro — это рабочее место менеджера контакт-центра, предназначенное для выполнения операций в едином интерфейсе без необходимости прямой работы с внешними системами.  
Данный репозиторий содержит только **end-to-end тесты** и используется для локального запуска, отладки сценариев и дальнейшего применения в CI/CD.
